# Plan Update Template

Use this shape when completing or materially changing a phase:

```md
Status: completed

Completed work:

- ...

Files changed:

- `path`

Validation:

- `command` passed
- `command` failed: reason
- Not run: reason

Known gaps:

- ...

Next:

- ...
```

Add a log entry:

```txt
YYYY-MM-DD - Phase N completed. Summary. Validation: command/status. Next: Phase N+1.
```
